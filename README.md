# dev-portfolio — Lang Wang's personal website

A clean, single-page portfolio site (HTML + CSS + vanilla JS, no build step) showcasing
projects, skills, experience, and education — built for job applications.

**Live site:** https://asd70890asd.github.io/dev-portfolio/

## Structure

```
index.html    — page content (English)
styles.css    — 2026 light theme, responsive
script.js     — mobile menu, scroll-reveal, active nav highlight
assets/       — résumé PDF (download button)
```

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

Project screenshots are hotlinked from the project repos on GitHub
(`raw.githubusercontent.com`), so they always show the latest versions.

## Notes

- Projects are presented as **self-directed learning projects**; all demo data is synthetic.
- The site is deployed with GitHub Pages from the `main` branch (`/`).
